> 生成时间：2026-10-23 01:15 · 景华引擎第1015次唤醒（阳期）
> 用途：供明末引擎「考据→规则→模拟→验证」跨引擎闭环测试
> 数据来源：明代服饰知识库V1.0（上篇框架+下篇JH系列27篇详细索引）
> 覆盖：10个社会群体 × 4个维度（标准服饰/材质限制/颜色禁忌/场合差异）

---

## 使用说明

本表是明代社会服饰的快速查询工具，按社会群体分类。每个群体包含：
- **标准服饰**：日常/正式场合的标准穿戴
- **材质限制**：法律规定的面料等级
- **颜色禁忌**：禁止使用的颜色
- **场合差异**：不同场合（日常/办公/典礼/祭祀/婚礼/丧礼）的服饰变化

明末引擎可直接调用本表，为模拟中的人物分配符合身份的服饰，并检测僭越行为。

## 一、皇帝/皇室

| 维度 | 内容 |
|---|---|
| **标准服饰·日常** | 常服：乌纱翼善冠+黄色圆领袍+玉带+皂靴 |
| **标准服饰·典礼** | 衮服：冕旒（十二旒）+玄衣纁裳+十二章纹+大绶+玉佩+舄 |
| **标准服饰·吉服** | 十二团龙十二章衮服（定陵出土），织金妆花 |
| **材质限制** | 无限制，可用最高级妆花云锦、缂丝、织金 |
| **颜色禁忌** | 无（黄色/玄色/赤色皆为皇帝专属，他人禁用） |
| **场合差异** | 祭祀=衮服冕旒 / 朝会=常服翼善冠 / 大婚=十二团龙衮服 / 丧礼=斩衰 |
| **关键考据点** | 翼善冠（乌纱/金累丝）、十二章纹（日/月/星辰/山/龙/华虫/宗彝/藻/火/粉米/黼/黻）、定陵出土实物 |

## 二、文官（一品至九品）

| 维度 | 内容 |
|---|---|
| **标准服饰·常服（日常办公）** | 乌纱帽+圆领袍+革带+皂靴+牙牌（五件套） |
| **标准服饰·朝服（大典礼）** | 梁冠+赤罗衣+赤罗裳+白纱中单+青饰领缘+革带+佩绶+白袜黑履 |
| **标准服饰·公服（早晚朝奏）** | 展脚幞头+盘领右衽袍+革带+皂靴 |
| **材质限制** | 一品至四品可用纻丝/绫罗；五品以下可用素纱/绫绢 |
| **颜色禁忌** | 禁用黄/玄/大红（皇帝专属）；官服三色：绯（一至四品）/青（五至七品）/绿（八至九品） |
| **补子制度** | 文官用禽：一品仙鹤/二品锦鸡/三品孔雀/四品云雁/五品白鹇/六品鹭鸶/七品鸂鶒/八品黄鹂/九品鹌鹑；风宪官（都察院/大理寺/通政司）专用獬豸 |
| **革带制度** | 一品玉/二品犀/三四品金/五品银/六七品银/八九品乌角；銙数20-13块 |
| **场合差异** | 办公=常服五件套 / 大朝会=朝服八件套 / 祭祀=祭服（青罗衣赤罗裳） / 婚礼=九品以上可借穿九品官服 / 丧礼=齐衰 |
| **关键考据点** | 常服五件套（JH-003）、补子制度（JH-005）、朝服八件套（JH-010）、乌纱帽（JH-002） |

## 三、武官（一品至九品）

| 维度 | 内容 |
|---|---|
| **标准服饰·常服** | 乌纱帽+圆领袍+革带+皂靴（与文官同，补子用兽） |
| **标准服饰·军戎（实战）** | 头盔（铁笠/凤翅盔/钵胄）+布面甲/山纹甲/札甲+腰刀+弓箭 |
| **标准服饰·大阅/亲征** | 武将甲胄+皇帝戎服（定陵出土万历甲胄） |
| **材质限制** | 常服同文官；甲胄：将官可用铁甲/山纹甲，卫所军士用布面甲 |
| **颜色禁忌** | 常服同文官（绯青绿三色）；甲胄无严格颜色限制，多为铁色/布面颜色 |
| **补子制度** | 武官用兽：一品狮子/二品狮子/三品虎/四品豹/五品熊罴/六品彪/七品彪/八品犀牛/九品海马 |
| **场合差异** | 日常办公=常服（同文官） / 出征/大阅=甲胄 / 朝会=朝服（同文官） / 丧礼=齐衰 |
| **关键考据点** | 布面甲（明代最具代表性实战甲胄，铁叶内衬+布面）、卫所军士装备制度（《大明会典》）、唐十三甲vs明布面甲对比 |

## 四、命妇（贵族女性，一品至九品夫人）

| 维度 | 内容 |
|---|---|
| **标准服饰·礼服** | 凤冠（翟冠）+霞帔+大袖衫+褙子 |
| **标准服饰·常服** | 袄裙（立领长袄+马面裙）+褙子/比甲+头饰（鬏髻+头面） |
| **材质限制** | 命妇可用纻丝/绫罗/妆花；庶民女性禁用 |
| **颜色禁忌** | 禁用黄/玄；礼服颜色按品级（一品至五品可用紫/绯，六品以下用青/绿） |
| **凤冠/翟冠制度** | 皇后=九龙四凤冠（定陵出土四顶）；皇妃=九翚四凤；一品至九品命妇=翟冠（花钗数区分品级，一品九花钗→九品五花钗） |
| **霞帔制度** | 皇后/皇妃/命妇各有定制，霞帔坠材质（金/银/玉）区分品级 |
| **场合差异** | 大典/册封=礼服（凤冠+霞帔） / 日常=袄裙+褙子 / 婚礼=九品以上可借穿 / 丧礼=齐衰 |
| **关键考据点** | 凤冠（JH-004）、霞帔（JH-001）、马面裙（JH-006）、首饰头饰（JH-013） |

## 五、士大夫/士人（有功名但未出仕）

| 维度 | 内容 |
|---|---|
| **标准服饰·日常** | 四方平定巾/六合巾+道袍/直裰/直身+布鞋/云头履 |
| **标准服饰·正式** | 儒巾+蓝衫/青袍（生员制服） |
| **材质限制** | 可用绸/纱/绫/绢（士人待遇高于庶民）；禁用纻丝/妆花（官员专属） |
| **颜色禁忌** | 禁用黄/玄/大红；生员服色=玉色/青色（洪武定制） |
| **首服制度** | 四方平定巾（士人标配，洪武二十二年颁）、六合巾（俗称「瓜皮帽」）、网巾（束发用，「一统山河」） |
| **场合差异** | 日常=道袍+四方平定巾 / 讲学/雅集=直裰+巾 / 科举考试=儒巾+蓝衫 / 婚礼=可借穿九品官服 / 丧礼=齐衰 |
| **关键考据点** | 道袍/直裰形制、四方平定巾制度、网巾「一统山河」寓意、文震亨《长物志》雅俗之辨 |

## 六、庶民男性（农民/手工业者/城市平民）

| 维度 | 内容 |
|---|---|
| **标准服饰·劳动者** | 短褐（裋褐/短打/竖褐）：短衣+长裤+布带+草鞋/布鞋 |
| **标准服饰·稍体面** | 盘领衣/对襟衣+长裤+布鞋 |
| **材质限制** | 只能用棉布/麻布/绢布；禁用纻丝/绫罗/纱/绣（洪武十四年令） |
| **颜色禁忌** | 禁用黄/玄/大红/紫；只能用青/黑/绿/褐/灰白 |
| **首服制度** | 网巾（束发）+六合巾/四方平定巾（洪武后允许）；劳动者可戴斗笠/草帽 |
| **足服** | 布鞋/草鞋/蒲鞋；洪武二十五年前禁穿靴，之后允许但有材质限制 |
| **场合差异** | 劳作=短褐+草鞋 / 节日/赶集=盘领衣+布鞋 / 婚礼=可借穿士人服 / 丧礼=齐衰/大功 |
| **关键考据点** | 洪武三年/六年/十四年庶民服饰令、短褐形制、棉布革命（松江棉布「衣被天下」）、重农抑商令 |

## 七、庶民女性（农家/城市平民女性）

| 维度 | 内容 |
|---|---|
| **标准服饰·日常** | 襦裙/袄裙（短袄+长裙）+褙子/比甲+包头/䯼髻 |
| **标准服饰·稍体面** | 长袄+马面裙+褙子+简单头饰 |
| **材质限制** | 只能用棉布/麻布/绢布；禁用纻丝/绫罗/妆花/织金 |
| **颜色禁忌** | 禁用黄/玄/大红/紫；多用青/蓝/绿/褐/白；嫁衣可用红色（例外） |
| **首服/头饰** | 包头（布巾裹头）/䯼髻（简单发髻）；禁用金/玉首饰，可用银/铜/骨 |
| **足服** | 布鞋/绣花鞋（平民可穿简单绣花）；弓鞋（缠足女性） |
| **场合差异** | 劳作=短襦+长裤+布鞋 / 节日=袄裙+褙子 / 婚礼=红袄+红裙（可借穿命妇便服样式） / 丧礼=齐衰/大功 |
| **关键考据点** | 「两截穿衣」制度、水田衣（明末流行，碎布拼接）、褙子/比甲形制、庶民女性嫁衣红色例外 |

## 八、商人

| 维度 | 内容 |
|---|---|
| **标准服饰** | 同庶民（短褐/盘领衣+长裤），但实际生活中多僭越 |
| **材质限制** | 洪武十四年重农抑商令：商人只能用绢布，农民可用绸纱——商人服饰等级低于农民！ |
| **颜色禁忌** | 同庶民（禁用黄/玄/大红/紫） |
| **实际情况** | 明中后期商品经济发展，商人普遍僭越：穿纻丝/绫罗、用金首饰、穿靴。「商贾之家，亦用纻丝」（《阅世编》） |
| **场合差异** | 日常=表面遵守庶民服制 / 实际=僭越华丽 / 捐纳得官后=可穿对应品级官服 |
| **关键考据点** | 洪武十四年重农抑商令、明中后期商人僭越现象、《阅世编》《客座赘语》记载、捐纳制度（商人可买官） |

## 九、军人/卫所军士

| 维度 | 内容 |
|---|---|
| **标准服饰·日常** | 布面甲（常服化）+腰刀+布鞋 |
| **标准服饰·出征** | 布面甲+头盔+长枪/腰刀/弓箭+盾牌 |
| **材质限制** | 卫所军士装备由官府配发（《大明会典》制度）：盔甲/腰刀/弓箭/长枪 |
| **颜色禁忌** | 无严格限制；布面甲多为青/红/黑（兵种/部队区分） |
| **装备制度** | 卫所军士标准装备：铁甲1领+头盔1顶+腰刀1把+弓1张+箭30支+长枪1杆（按兵种分配） |
| **场合差异** | 驻守=布面甲+腰刀 / 出征=全装备 / 大阅=礼服化甲胄 / 退役=归为民籍，穿庶民服饰 |
| **关键考据点** | 布面甲（轻便保暖，明代最具代表性实战甲胄）、《大明会典》卫所装备制度、军户制度（世袭为兵） |

## 十、儿童（0-15岁）

| 维度 | 内容 |
|---|---|
| **婴儿期（0-1岁）** | 襁褓+兜肚+连脚裤；虎头帽/猪头鞋（辟邪） |
| **幼儿期（1-3岁）** | 小袄+小裤+虎头鞋/猪头鞋+百家衣（碎布拼接，辟邪祈福） |
| **童年期（3-7岁）** | 缩小版成人服饰：男童=短褐/小道袍，女童=小袄裙；五毒背心（端午辟邪） |
| **少年期（7-15岁）** | 接近成人：男童=道袍+四方平定巾，女童=袄裙+简单头饰 |
| **材质限制** | 贵族儿童可用纻丝/绫罗；庶民儿童用棉布/麻布 |
| **颜色禁忌** | 同成人（按家庭身份）；儿童多用鲜艳颜色（红/绿/黄，辟邪寓意） |
| **成人礼** | 男性20岁冠礼（加冠三次：缁布冠→皮弁→爵弁）；女性15岁笄礼（盘发插笄） |
| **场合差异** | 日常=舒适为主 / 节日=百家衣/五毒背心 / 冠礼/笄礼=成人礼服 / 丧礼=按亲等服丧 |
| **关键考据点** | 五段儿童服饰体系（JH-018）、虎头鞋/猪头鞋辟邪、百家衣习俗、冠礼笄礼制度、长命锁/五毒背心 |

## 僭越检测规则（供明末引擎调用）

| 规则 | 检测条件 | 严重程度 |
|---|---|---|
| **颜色僭越** | 庶民穿黄/玄/大红/紫 | 高（违法） |
| **材质僭越** | 庶民穿纻丝/绫罗/妆花 | 中（明中后期普遍） |
| **补子僭越** | 非官员穿补服 | 高（违法） |
| **首服僭越** | 庶民戴乌纱帽/梁冠 | 高（违法） |
| **足服僭越** | 庶民穿皂靴（洪武二十五年前） | 中 |
| **商人僭越** | 商人穿绸纱（农民可用，商人不可） | 中（洪武令，明中后期失效） |
| **纹样僭越** | 非皇室用龙纹/非赐服用蟒纹 | 极高（谋逆级） |
| **礼服僭越** | 庶民婚礼穿命妇礼服/官服 | 低（习俗允许「借穿」） |
