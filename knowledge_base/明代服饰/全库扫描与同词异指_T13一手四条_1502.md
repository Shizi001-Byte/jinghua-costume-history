# 全库扫描与同词异指：T13 的一手四条（1502 轮）

## 〇、先说这条最可能错在哪

我把「仪注里出现某件衣服」当成了「这件衣服已在行用」。最坏情况是：1370 年册封仪写「亲王各具九章冕服」，可能只是行礼时把亲王的冕服按皇太子规格**借用/拟具**，不是亲王自有之制；1384 年亲王冠礼写「具九旒冕…皆在笥」，「在笥」是**收在箱子里备着**，冠礼当场戴的是网巾、翼善冠，冕服直到朝贺才穿——我若把「在笥」读成「已定制」，就是把「备而未用」当成了「已成制度」。

所以下面的结论一律加限定：**仪注证明「行礼时有这套东西」，不证明「有诏定过这套东西」。**按 1473 判据（会典记令、实录记行），这两件事不能互相顶替。T13 的 level 因此不升。

## 一、为什么要扩窗口

1500 轮查过卷 224–230（洪武二十六年全年，7 卷 27644 字符），结论「本年无制度性冕服文本」。但那只是**一年**。施子列的下一步本来就是「扩查 223/231」，而本地 `lib/raw_volume/ms30/sl/` 里其实躺着 **238 页**整卷正文——一直没有全扫。本轮把窗口从 7 卷扩到 238 页。

## 二、扩了窗口还不够：两个前提

**前提一：繁简归一。** 这份语料繁简混杂（同一句里「礼部」与「尚書」并存）。不归一时：

| 词 | 归一前 | 归一后 | 说明 |
|---|---|---|---|
| 曲脚 | 0 | 1 | 056「曲**腳**幞頭」，简形查不到繁体 |
| 衮冕 | 0 | 30（21 页） | 反之「袞冕」原 30 → 归一 0 |
| 真紅 | 5 | 0 | 归一成「真红」 |
| 等殺 | 7 | 0 | 归一成「等杀」 |

这张表的杀伤力不在 T13，在**所有历史上写着「0 命中」的阴性结论**：它们的真假取决于当时用的是哪套字形。T10（宦官内使冠服）的 hit_note 里就写着「『描金』『曲脚』…0 命中」——「曲脚」实际在 056 有 1 处（乐工服饰，「皆戴曲腳幞頭」）。那不是 T10 的冠服条文，但「0 命中」这句话本身是假的。**方法层的病，不能用更努力地检索来治。**

**前提二：同词异指。** 「九旒九章」在实录里不只指宗室：

- 038（洪武二年封城隍）：「京都城隍衮冕十有二章，开封等五府封王及各府封公者**九旒九章**，各州县封侯伯者**七旒七章**」——这是**神祇章服**。若只数字面，「洪武二年已有九旒九章之制」就会被当成亲王的证据，差 24 年、换个对象。
- 093/110/152 的「九章」是「回銮乐歌三十九章」「汉律九章」「诗九章」——纯同字异义。

| 页 | 年 | 原文 | 性质 |

| 051 | 洪武三年四月 | 「皇帝于谨身殿具衮冕…亲王各具**九章冕服**」 | 册封仪注（行） |
| 155 | 洪武十六年六月 | 「**诏更定冕服之制**…国初所制虽参酌古制然尚未备，宜加考定以成一代典章」 | 诏（皇帝冕服） |
| 165 | 洪武十七年九月 | 礼部尚书任昂奏更定亲王冠礼「具**九旒冕**、翼善冠、绛纱袍…皆在笥」 | 冠礼仪注（行） |
| 197 | 洪武二十二年八月 | 「**诏定王世子冠服礼仪**，冕服各七章，冕缫七就，前后各**七旒**，旒七玉…圭长七寸」 | 诏（世子，令） |

四条合起来说明：明代宗室冕服**不是 1393 一次定成**，而是 1370 册封仪已在用 → 1383 皇帝冕服更定 → 1384 亲王冠礼在用 → 1389 世子七旒诏定 → 1393 会典所载是汇编/著为定式。

## 四、判词与为什么不升级

1. **「亲王九旒初定 1393」不成立**：1370 已有「九章冕服」在册封仪中使用，1384 冠礼明列「九旒冕」。
2. **世子七旒一手在 1389**（页 197 诏令），不是 1393；库内 trap 那句「世子1393七旒」已订正。
3. **郡王七旒仍无一手**：全库「郡王」与「七旒」同段命中 0 页（阴性，带窗口）。
4. **仍不升 level**：郡王七旒缺一手；亲王九旒只有仪注「行」无诏「令」。一条里只要有一项无一手，整条就留在 secondary_only——这是等级纪律，不是保守。

## 五、残留风险（写清楚，别以为窗口就是完整的）

- 238 页**不是全帙**：编号 1–257，缺 19 卷（28/36/37/39/44/109/183/184/210–219/245）。其中 210–219 正好落在洪武二十四年段（T4 更定尺寸之年），所以 **T4 侧不能引用本层当全窗口**。
- **每卷完整度未测**：225 卷只有 2273 字符，一整月的实录不该这么短。诗词汇页面可能只给了摘要或分页。在测出「每卷字符数 vs 同期卷中位」之前，「全库 0 命中」这类结论都要打折扣。
- 155 页的十二旒在「历代之制」征引段里（有虞/周/汉/唐/宋一路列下来），明代自身形制要逐字分辨哪句是今制。

## 七、金句

- 窗口扩了，不加上前提，只是把一个窄的假阴性换成一个宽的假阴性。
- 「0 命中」不是结论，是「在某个字形、某个范围、某个所指下 0 命中」的缩写；省掉后缀，它就变成谎言。
- 同一个「九旒」，城隍神也穿，亲王也穿——字面是索引，不是证据。
- 仪注证明有人穿过，诏令证明有人定过。这两件事在实录里挨着，在制度史里差着几十年。
