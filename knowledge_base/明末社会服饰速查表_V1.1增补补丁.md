## 补丁一：女性禁色双轨制（P0，纠正误判）

### V1.0 的问题
V1.0 把"绝对禁区"统一定为：黄色 / 玄色 / 龙凤纹。这在**男性/军民僧道**维度是对的，但**漏了女性专有的禁色**——大红、鸦青。

结果：案例2（正德庶民妇女穿大红织金）被 detector 判为 high（因为按"非绝对禁区→受时期乘数×1.0"处理），实际应为 **critical**（大红对妇人属绝对禁色，不受乘数衰减）。

### 明代禁色是分性别双轨的（原始条文）

| 适用对象 | 禁色 | 条文 | 出处 | 生效年 |
|---|---|---|---|---|
| 军民僧道（男性） | **玄、黄、紫** | "官吏及军民僧道人等衣服帐幔，并不许用玄、黄、紫三色，并织绣龙凤文，违者罪及染造之人" | 《大明会典》/《明史·舆服志》 | 洪武二十六年 |
| 民间妇人（女性） | **大红、鸦青、黄** | "凡妇人袍衫，止用紫绿桃红及诸浅淡颜色，不许用大红、鸦青、黄色。带用蓝绢布" | 《大明会典》卷61 | 洪武五年 |
| 庶人通用 | **黄** | "庶人……杂色盘领衣，不许用黄" | 《明史·舆服志》 | 洪武三年 |

### 接入方式

```python
ABSOLUTE_FORBIDDEN = {
    "male":   ["玄", "黄", "紫", "龙凤纹"],
    "female": ["大红", "鸦青", "黄", "龙凤纹"],
    "common": ["黄", "龙凤纹"],
}
# 判案时按案例人物性别选择对应禁色表
# 命中任一 → critical，不受时期乘数影响
```

**注意**：紫色对男性是禁色，但女性"紫绿桃红"是**允许**的（T7原文"止用紫绿桃红"）。性别判断必须在禁色匹配之前完成，否则会把合规的紫衣妇人误判。

## 补丁二：尺寸规制维度（P1，补齐第四维）

### V1.0 的问题
V1.0 只有三维：颜色 / 面料 / 纹样。缺"尺寸"这一维。

结果：案例7（崇祯庶民妇女穿大袖衫，袖宽过一尺）被 detector 判为 none（漏检）。实际双重僭越：
1. 大袖衫是**命妇服制**（品级标志）
2. 袖宽过一尺违反庶民衣制尺寸上限

### 原始条文

| 条文 | 内容 | 出处 | 生效年 |
|---|---|---|---|
| 庶人衣制尺寸 | "衣长去地五寸，袖长过手六寸，**袖椿广一尺**，袖口五寸" | 《明史·舆服志》 | 洪武二十三年 |
| 命妇大袖衫 | "命妇冠服……**大袖衫，用真红色**。一品至五品……" | 《大明会典》 | 洪武二十四年 |

### 第四维字段设计

```python
DIMENSION_SIZE = {
    "衣长": {"庶民上限": "去地五寸", "说明": "衣摆离地不超过五寸"},
    "袖长": {"庶民上限": "过手六寸", "说明": "袖口超出手指六寸"},
    "袖宽": {"庶民上限": "一尺", "说明": "袖椿（袖身最宽处）广一尺"},
    "袖口": {"庶民上限": "五寸", "说明": "袖口宽五寸"},
}

# 特殊款式：大袖衫属命妇服制，庶民妇女穿着即僭越（与尺寸叠加计）
STYLE_TRAPS = {
    "大袖衫": {"等级": "命妇", "后果": "僭用命妇服制"},
}
```

### 为什么这一维重要
尺寸是最容易被忽略、又最容易实测的维度——颜色可以辩称"这是浅红不是大红"，面料可以说"这是棉不是丝"，但**袖宽过一尺是拿尺子量就能定的**。明代立法者把尺寸写进律令，恰恰是因为它是可执行的判据。

## 补丁三：规则生效年份（P0，最严重，可推广到所有引擎）

### V1.0 的问题
detector 每条规则没有时间边界，等于**所有律条永久有效、无限回溯**。

结果：案例9（洪武商人穿貂裘）被 detector 判为 critical，依据是"禁商贩仆役服用貂裘"。但——

**貂裘禁令是正德元年（1506）才有的**："正德元年，禁商贩、仆役、倡优、下贱不许服用貂裘。"

案例在洪武年间（1368 起），相差一百三十多年。**这是时代错置：用后世律条判前朝案例。**

### 修复方案

```python
RULES = [
    {
        "id": "R-MAT-001",
        "rule": "商贾之家止穿绢布",
        "source": "《明太祖实录》洪武十四年",
        "effective_from": 1381,
        "effective_to": 1644,
        "applies_to": ["商人"],
        "severity_base": "critical",
    },
    {
        "id": "R-MAT-007",
        "rule": "禁商贩仆役倡优下贱服用貂裘",
        "source": "《明史·舆服志》正德元年",
        "effective_from": 1506,   # ← 关键：正德元年才有
        "effective_to": 1644,
        "applies_to": ["商人", "仆役", "倡优"],
        "severity_base": "high",
    },
]

def check_rule_applicable(rule, case_year):
    if case_year < rule["effective_from"]:
        return "该时期无此禁令"   # 不能计入僭越，但应输出说明
    if case_year > rule["effective_to"]:
        return "该禁令已失效"
    return "applicable"
```

### 判案输出要求
不在有效期内时，**不要静默跳过**，要显式输出"该时期无此禁令"——因为"没这条律"和"有律但没违"是两种完全不同的结论，前者是立法空白，后者是守法。

### 可推广的教训
任何规则库都必须带时间戳，否则就是**拿今天的尺子量昨天的事**。这条不只适用于明末引擎：
- 景华的考据规则（唐宋明三代禁令不同，混用会出错）
- 任何"从史料提炼规则"的引擎都有这个风险
